That can't be done in code anymore — once a mapId is set (you now have one), Google ignores the styles MapOption, because style comes from the Map ID. So it has to be configured in Google Maps Platform.
Steps
1. Go to Google Maps Platform → Map Management (https://console.cloud.google.com/google-maps-platform/map-management) (or Google Maps → Advanced → Map management).
2. Open map ID ed23aa98c0a50d9945c2d1c7, then edit/create its style.
3. Turn off Points of interest → Business (and the categories below), leave Roads on.
4. Save and associate.
Style JSON to paste in "Custom style" mode
[
  { "featureType": "poi.business", "stylers": [{ "visibility": "off" }] },
  { "featureType": "poi.attraction", "stylers": [{ "visibility": "off" }] },
  { "featureType": "poi.school", "stylers": [{ "visibility": "off" }] },
  { "featureType": "poi.sport", "stylers": [{ "visibility": "off" }] },
  { "featureType": "poi.medical", "stylers": [{ "visibility": "off" }] },
  { "featureType": "poi.administrative", "stylers": [{ "visibility": "off" }] }
]
poi.business is the one that actually kills shop names. The others are optional if you also find hospitals/schools/sports venues noisy. Don't disable road, road.local, or transit — those are your street names.
Two notes: allow ~5 minutes for the change to propagate, and this applies to every user of that Map ID.
Your own project markers are custom AdvancedMarkerElement content, not POIs, so they're unaffected.
If you'd rather not touch the console, the alternative is dropping the mapId from googleMaps.ts and using the legacy styles option — but you'd lose the custom-map styling and vector rendering, so I'd recommend the console route.
