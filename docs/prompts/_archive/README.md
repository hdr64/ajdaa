# Finished OpenCode tasks (archive)

Prompts and reports of tasks that were reviewed and merged. Kept for history; nothing here is active. Paths and branch names inside old prompts (`lane/auth`, `ajda-wt\...`, `feat/backend-admin`) describe the setup at the time and no longer exist.

- `early/`: first hand-offs before the wave process (queue engine for OpenCode, announcement bar for agy).
- `wave1/`: review0 (audit), foundation (schema, permissions), sec0 (security criticals), deploy (test instance, CI) with their fix rounds.
- `wave2/`: projects (3D link, edit form, PDF buttons), users wizard, past projects, careers, plus the careers review report.
- `w3/`: login password eye button; auth A, A2, B and C (email verification, email code, authenticator 2FA, passkeys).
- `w4/`: admin i18n core, l1, l2, l3 (l2 and l3 were done outside the prompt process in commits `17af876`..`f997744`; their prompts are kept as the spec), public polish, create-dev-user.
- `w5/`: client fixes, server hardening (A and B), production readiness (A and B), careers toggle, inquiry detail.

Active tasks live one level up in `docs/prompts/` (see its README). Review reports live in `docs/reviews/`.
